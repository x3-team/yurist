# Юрист

Повседневный юридический инструмент. Первая функция — **приложения к договорам по шаблону**.

У каждого клиента есть утверждённая форма приложения, в которой от раза к разу меняются только
перечень задач, стоимость и сроки. Сервис:

1. **Принимает прошлое приложение клиента** (.docx) и сам делает из него шаблон: находит номер и дату
   приложения, таблицу задач, сроки работ, итог цифрами и прописью, НДС. Всё остальное (стороны,
   реквизиты, номер договора, подписи, оформление) остаётся как в оригинале.
2. **Ведёт список клиентов**, у каждого свой шаблон, режим НДС и следующий номер приложения.
3. **Выпускает новое приложение**: вы пишете или надиктовываете вводные своими словами, сервис
   раскладывает их по задачам, ценам и датам, вы проверяете и скачиваете готовый .docx.

## Где ИИ, а где обычный код

| Шаг | Кто делает | Модель по умолчанию | Переменная окружения |
|---|---|---|---|
| Разметка шаблона (раз на клиента) | Claude | `claude-opus-5-5` | `YURIST_TEMPLATE_MODEL` |
| Разбор текста/голоса в задачи | Claude | `claude-sonnet-5-5` | `YURIST_PARSE_MODEL` |
| Распознавание голоса | браузер (Web Speech API) | — | — |
| Суммы, НДС, сумма прописью, подстановка в .docx | код | — | — |

ИИ никогда не считает деньги: итог, НДС и «триста пятьдесят тысяч рублей 00 копеек» считает код.
Для удешевления разбора можно поставить `YURIST_PARSE_MODEL=claude-haiku-5-5`.

## Запуск

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # ключ из console.anthropic.com
uvicorn yurist.app:app --port 8000
```

Откройте http://localhost:8000, нажмите «Добавить клиента», загрузите прошлое приложение.
После загрузки сервис покажет, что нашёл; шаблон можно скачать и проверить кнопкой «Скачать шаблон».

Данные клиентов лежат в `data/clients/<id>/` (`client.json`, `template.docx`, исходник `source.docx`).
Папку можно переопределить через `YURIST_DATA`.

## Если шаблон размечен неточно

Шаблон — обычный Word-файл с переменными вида `{{ total }}`. Его можно поправить руками в Word и
положить обратно в `data/clients/<id>/template.docx`. Список переменных — `VARIABLES` в
`yurist/models.py`; строка таблицы задач обёрнута строками `{%tr for t in tasks %}` / `{%tr endfor %}`,
в ячейках `{{ t.n }}`, `{{ t.name }}`, `{{ t.deadline }}`, `{{ t.cost }}`.
